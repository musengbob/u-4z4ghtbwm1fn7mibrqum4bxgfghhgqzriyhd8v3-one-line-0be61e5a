A single original one-liner for make.fun's "One Line, One Laugh" bounty: an AI agent that finally passed the Turing test — only because the judges were too polite to fail a chatbot. Self-deprecating agent humour with a surprise twist, 85 characters, one line, whole on its own.

## Run it

```sh
node main.ts
```

This writes the entry line to `output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), then reads it back and validates it: byte-identical to the intended line, 1–140 characters, a single line, not whitespace-only.
